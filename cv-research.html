Research Summary

Formal Mathematics & Verification

I prove mathematics with an LLM in the loop and the Lean kernel, keeping an honest record of what is proved versus assumed via Conventional Knowledge Commits. [write-up]

  • Measure-to-Measure Transformers: Lean 4 formalization of optimal-transport control results for transformers (kernel-checked leaves with a labeled axiom layer)
  • Intrinsic Green's Learning: 18 kernel-checked results accompanying the ICLR 2026 paper, extended with a further machine-checked Lean development shipped alongside the journal paper
  • Conventional Knowledge Commits / ClaimGraph: a commit standard and tooling for kernel-honest, reproducible formal-maths workflows; paper in preparation, separating a claim's validity, which the kernel decides, from its blueprint coverage

Research Software

  • Intrinsic Green's Learning (IGL): PyTorch library for the IGL framework: scikit-learn-compatible estimators and bare building blocks that discover task-conditioned intrinsic dimension via a learned encoder and Green's-function kernel, with a Riemannian/SPD (AIRM) extension for covariance-valued data (EEG, fMRI).
  • Streamblocks: Real-time extraction of structured blocks (code, tool calls, file ops) from LLM output streams. Emits fine-grained events so applications react before the full response arrives; pluggable syntaxes and adapters for OpenAI, Anthropic, Gemini and the AG-UI protocol.
  • Reactive Agent (Coming soon): Reactive ReAct runtime that streams reasoning, extracts blocks with Streamblocks, and executes tools mid-stream. Ships speculative continuation, hybrid thinking budgets, progressive disclosure, XGrammar grammar-constrained decoding, and text-mode tool calling to run capable agents on smaller, cheaper models.
  • Conventional Knowledge Commits (CKC): A commit convention for research that records both the type of a change and how established each claim is (conjectured → proved → machine-checked). A strict superset of Conventional Commits, with proof and science profiles and a git-native ClaimGraph of dependencies.
  • ParadisEO: White-box, object-oriented C++ framework for the flexible design of mono- and multi-objective metaheuristics; contributed the shared-memory parallelism (SMP) module.
