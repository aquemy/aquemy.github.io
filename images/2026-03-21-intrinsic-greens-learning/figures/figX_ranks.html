d vs r_NL vs r_K — Three Different Notions of Dimension

the manifold's intrinsic dimension d, the embedding rank r_NL, and IGL's kernel-relative rank r_K are distinct quantities

d (intrinsic dimension) is a topological invariant: the minimum number of coordinates to parameterize the manifold. It is fixed by the shape, not the embedding. r_NL = r(ι) (embedding rank) is the minimum number of nonlinear functions φₖ(θ) such that all D ambient coordinates can be written as linear combinations: ι = W·φ(θ). For the Swiss Roll, t·cos(t) and t·sin(t) are algebraically independent despite both depending on the single parameter t — so r_NL = 3 > d = 2. r_K (kernel-compatible rank) is what IGL's gates actually discover for reconstruction: for smooth aperiodic embeddings (MLP with tanh), r_K = d; for periodic embeddings (torus), r_K = r_NL. The full hierarchy d_eff(class) ≤ d ≤ r_K ≤ r_NL ≤ D is verified across 13 manifold settings.
