Summary

I work at the intersection of machine learning, mathematics, and software engineering. My research develops geometric and PDE-based methods for machine learning, along with interpretability and reproducibility tooling, and I build the systems that put them into practice.

My main research interest is differential geometry for AI. My primary work here, Intrinsic Green's Learning, discovers and reconstructs the unknown, task-conditioned intrinsic manifold underlying a dataset, modelling the target function on it as the solution of a linear PDE learned from data, scaling linearly in the intrinsic dimension while staying interpretable. It was presented at the AI & PDE Workshop @ ICLR 2026.

I am in general interested in AI Safety, which motivates my mechanistic-interpretability work above; I completed the ML4Good Technical Track and BlueDot Impact's Technical AI Safety course.

My doctoral thesis brought end-to-end classification to unstructured spaces, applied to judicial decisions, cutting the expertise the usual ML workflow demands. A detailed summary is here.

I am a member of the Eloquence AI Community of Experts (Horizon Europe). You can view my research CV or my engineering CV.

Current Work

Geometry & PDE for ML

Intrinsic Green's Learning and its extensions: an SPD-manifold (AIRM) framework for cross-subject motor-imagery BCI, geometric readouts for language-model embeddings, and MHALM, my entry to the OpenAI Parameter Golf challenge: a geometric multi-kernel language model trained under a 16 MB / 10-minute budget.

PapersIntrinsic Green's Learning (ICLR 2026) · IGL on the SPD manifold (in prep) · Riemannian geometry for LM embeddings (under review) · IGL for contextual word embeddings (in prep)

WritingIntrinsic Green's Learning · MHALM: Parameter Golf

Mechanistic Interpretability

The decoupling index κ and a signed-hypergraph account of MLP gating structure: a measurable diagnostic that maps, and bounds, what interpretability tools can detect about computation in superposition (validated across GPT-2-small).

PaperThe Decoupling Index κ (under review, BlackboxNLP)

Machine-Checked Mathematics

Proving mathematics with an LLM in the loop and the Lean kernel, keeping an honest record of what is proved versus assumed via Conventional Knowledge Commits and the ClaimGraph.

WritingMachine-checked mathematics, with an LLM in the loop

ToolsConventional Knowledge Commits · ClaimGraph

Agentic Systems

Reactive agent runtimes with real-time block extraction (Streamblocks), speculative tool execution, and grammar-constrained (XGrammar) decoding, plus in-progress research on SFT/RL to run capable agents on smaller, cheaper models.

Software & Open Source

AI Research

Intrinsic Green's Learning (IGL)

Python / PyTorch

Author & maintainer · Active

PyTorch library for the IGL framework: scikit-learn-compatible estimators and bare building blocks that discover task-conditioned intrinsic dimension via a learned encoder and Green's-function kernel, with a Riemannian/SPD (AIRM) extension for covariance-valued data (EEG, fMRI).

Github Pypi Docs

Agentic Systems

Streamblocks

Python / asyncio

Author & maintainer · Active

Real-time extraction of structured blocks (code, tool calls, file ops) from LLM output streams. Emits fine-grained events so applications react before the full response arrives; pluggable syntaxes and adapters for OpenAI, Anthropic, Gemini and the AG-UI protocol.

Github Pypi

Reactive Agent

Python / PydanticAI

Author & maintainer · Early research

Reactive ReAct runtime that streams reasoning, extracts blocks with Streamblocks, and executes tools mid-stream. Ships speculative continuation, hybrid thinking budgets, progressive disclosure, XGrammar grammar-constrained decoding, and text-mode tool calling to run capable agents on smaller, cheaper models.

Formal Mathematics & Verification

Conventional Knowledge Commits (CKC)

Specification

Author · Published (v0.1)

A commit convention for research that records both the type of a change and how established each claim is (conjectured → proved → machine-checked). A strict superset of Conventional Commits, with proof and science profiles and a git-native ClaimGraph of dependencies.

Website Github

ckc-tools

Python

Author & maintainer · Published

Git hooks and validators enforcing CKC on every commit, including an honesty gate that cross-checks 'machine-checked' claims against the Lean kernel via #print axioms and rejects silent sorryAx contamination.

Github

ClaimGraph

Python / Cytoscape.js

Author & maintainer · Published

Builds, queries and visualizes the dependency graph of CKC claims: effective status over the transitive closure, and the blast-radius of a refutation. Includes a static web viewer and worked examples (four-colour theorem, FLT, Kepler conjecture).

Website Github
